Educational Learning Blueprint

How this web app is built under the hood

1. HTML Structure & Semantic Markup

The application uses semantic HTML tags like <header>, <main>, and <footer>. Modals use fixed positioning overlays and UI cards update dynamically without page reloads.

2. CSS Styling & Modern UI (Tailwind CSS)

We leverage utility-first CSS via Tailwind CSS to construct a dark theme with backdrop filters, smooth hover animations, and fully responsive layouts for desktop and mobile screens.

3. Automatic Account RBAC Detection

The app inspects user email strings upon Google sign-in or manual input. If the email matches any of the 6 hardcoded board member emails, the application unlocks board administration privileges dynamically.
